# 📚 Интерактивный программный комплекс для тестирования знаний иностранных языков

Веб-приложение для проведения интерактивного тестирования знаний иностранных языков студентов.  
Преподаватель может загружать тесты из Excel-файлов, а студенты — проходить их в браузере с автоматической проверкой результатов.

## 🚀 Демо

[👉 Открыть демо](https://language-test-app-seven.vercel.app/)

## ✨ Возможности

- 👨‍🏫 **Режим преподавателя** — создание и управление тестами
- 📊 **Загрузка тестов из Excel** — автоматическое преобразование таблицы в интерактивный тест
- 📝 **Разные типы вопросов** — вопросы с вариантами ответа и открытые вопросы
- 🔊 **Аудиозадания** — возможность использовать аудиоматериалы в тестах
- ⏱️ **Ограничение времени** — автоматический отсчёт времени прохождения
- 👨‍🎓 **Режим студента** — прохождение назначенных тестов
- 📈 **Автоматическая проверка** — подсчёт правильных ответов и итогового результата
- 💾 **Сохранение результатов** — результаты тестирования сохраняются в базе данных
- 📋 **Просмотр результатов** — преподаватель может просматривать результаты студентов
- 📱 **Адаптивный интерфейс** — корректная работа на компьютерах, планшетах и мобильных устройствах
